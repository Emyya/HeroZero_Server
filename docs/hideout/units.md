# HIDEOUT — UNITS (assets/hideout_units)

## Data origin

This document describes the hideout units from the image metadata (assets/hideout_units) and the real data in `constants_json.data` (key `hideout_units`).

### Image naming convention

- `attacker.webp`, `defender.webp` — single sprites for each robot.

- `wall_1..wall_4.webp` — 4 appearance stages of the wall (level 1 to 4).

- There is no image for `professor` (it is generated by code).


### Field legend per level (stage)

- **HP**: unit life (`stat_stamina`).

- **ATK**: attack (`stat_strength`).

- **Critical / Dodge**: % critical and dodge (`stat_critical_rating` / `stat_dodge_rating`).

- **Build time**: unit production time.

- **Resources on destroy**: glue/stone dropped when destroyed (for the defender).
